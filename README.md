# dobby-widget

Public data for **Dobby**, the Tamagotchi-style iPhone widget (Scriptable) for the Etsy shop [ChefLabNotes](https://www.etsy.com/shop/ChefLabNotes).

- `status.json`: Dobby's current mood, message, challenge sales (x/10), last post and next task. Updated automatically.
- `img/felice.png`, `img/affamato.png`, `img/lavoro.png`, `img/dorme.png`: the four mood sprites.

Read by the widget from `https://raw.githubusercontent.com/domve10/dobby-widget/main/status.json`.
